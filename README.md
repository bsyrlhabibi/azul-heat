# Azul Heat: Two Runners
[![Competition](https://img.shields.io/badge/competition-gta6--01-blue)](https://make.fun/bounty/gta6-01) [![Prize](https://img.shields.io/badge/prize-%241%2C666%20USDC-green)](https://make.fun/bounty/gta6-01) [![Entries](https://img.shields.io/badge/entries-open-orange)](https://make.fun/bounty/gta6-01)

An original open-world crime game set in Bahía Azul, a sun-soaked coastal city of six districts, at permanent golden hour. Play as two switchable runners — Lucía Ferro, a courier with gifted hands, and Marco Reyes, an ex-mechanic whose cars refuse to die — stealing rides, running six story missions for Tía Carmen, El Contador and DJ Prisma, and outrunning a police force that answers with patrols, roadblocks and a helicopter. Side gigs, safehouses, per-district reputation, a phone full of story, three synth radio stations and a save system round out the run — all in vanilla JS and canvas, with zero assets and zero network.

## Run it
Hand the entry in with `node main.ts` (writes `game/`, `screenshots/` and `dossier.json` to the output dir), then serve it with `node serve.ts` — or simply open `game/index.html` in a desktop browser after running `node main.ts`. Keyboard and mouse required; everything runs offline.
